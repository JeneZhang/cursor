# 3D 贪吃蛇

基于 Three.js 的浏览器 3D 贪吃蛇小游戏。

## 运行

在项目根目录启动静态服务器，然后打开页面：

```bash
npx --yes serve snake-3d -p 4173
```

浏览器访问：<http://localhost:4173>

## 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 前后左右移动 |
| Q / E | 向下 / 向上 |
| 方向键 | 同 WASD 的水平移动 |
| 空格 | 暂停 / 继续 |
| 鼠标拖拽 | 旋转视角 |

## 规则

- 吃掉红色发光食物 +10 分，蛇身变长
- 撞墙或咬到自己则游戏结束
- 得分越高，移动速度越快
- 最高分会保存在浏览器本地
