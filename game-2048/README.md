# 2048 小游戏

浏览器里的 2048：同方向滑动整块棋盘，相同数字撞在一起就合并，目标是拼出 **2048**。

React 19 + TypeScript + Vite，纯前端，无后端依赖。规则逻辑写成纯函数并有单元测试覆盖。

## 玩法

- **移动**：方向键、`WASD`、`HJKL`，或直接在棋盘上滑动（触屏滑动、鼠标拖拽都可以），也可以点屏幕上的方向键
- **合并**：一次移动里，同一个方块只会合并一次（`4 4 4 4` 左移得到 `8 8`，不是 `16`）
- **计分**：每次合并加上合并后的数字；最高分按棋盘尺寸分别记录，存在浏览器本地
- **撤销**：`U` 或 <kbd>Ctrl</kbd>+<kbd>Z</kbd>，最多回退 12 步
- **重开**：`R`
- **棋盘**：支持 3×3 / 4×4 / 5×5 / 6×6
- **通关**：出现 2048 会弹出提示，可以选择「继续挑战」冲更大的数字

## 运行

需要 Node.js 20+。

```bash
cd game-2048
npm install
npm run dev
```

打开提示的本地地址（默认 `http://localhost:5175`）。

```bash
npm test     # 规则逻辑单元测试
npm run build   # tsc --noEmit + vite build
npm run preview # 预览生产构建
```

## 结构

- `src/lib/game.ts` — 规则内核：移动、合并、随机生成、胜负判定。纯函数，随机数由参数注入，方便测试
- `src/lib/session.ts` — 一局游戏的会话状态：撤销栈、最高分、重开与换棋盘的 reducer
- `src/lib/storage.ts` — 最高分的本地存储读写（读写失败时降级为不持久化）
- `src/hooks/` — 会话状态、键盘控制、滑动控制
- `src/components/` — 棋盘、方块、计分板、结算浮层、方向键
- `src/styles/global.css` — 全部样式，沿用仓库既有的配色变量，跟随系统深色模式

## 动画怎么做的

`move()` 返回的方块列表里，合并出来的方块带着 `mergedFrom`：两个来源方块被移到了合并后的格子上。渲染时先画这两个来源方块，再把合并结果盖在上面。来源方块的 DOM 节点在上一帧还在旧位置，于是 `transform` 过渡把它们滑到一起，合并结果延迟 100ms 弹出，下一次移动时来源方块才被移除。

## 测试


覆盖的点包括：滑动与合并方向、一次移动内不重复合并、无效移动不生成新方块、分数累计、棋盘填满且无相邻相同数字时判负、拼出 2048 判胜与「继续挑战」、撤销恢复棋盘与分数、最高分按尺寸分别保留、撤销栈上限。
