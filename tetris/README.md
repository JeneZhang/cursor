# 俄罗斯方块

纯 HTML / CSS / JavaScript 的经典俄罗斯方块，不需要构建，也不加载外部依赖。用浏览器直接打开 `index.html`，或把 `tetris/` 目录当作静态站点即可。

## 运行

在仓库根目录或本目录启动一个静态服务器：

```bash
cd tetris
python3 -m http.server 8765
```

然后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

也可以直接双击 `index.html`。页面只使用相对路径的本地脚本。

## 操作

- 任意键，或点击「开始游戏」开始
- `←` `→` 左右移动
- `↑` 顺时针旋转（贴墙或贴地时会做简单墙踢）
- `↓` 软降（每格 1 分）
- `空格` 硬降（每格 2 分，立即锁定）
- `P` 暂停 / 继续
- 游戏结束后按 `Enter`、空格，或点击「再来一局」

页面下方有触控按钮：左、右、旋转、下落、硬降、暂停。

棋盘右侧始终显示操作提示、下一块、分数、最高分、消行和等级。落点以同色空心残影表示。

## 规则

- 场地 10×20，包含 I、O、T、S、Z、J、L 七种方块，颜色各不相同
- 使用 7-bag 随机：每 7 个方块为一组，组内不重复
- 消除 1 / 2 / 3 / 4 行得分：`100 / 300 / 500 / 800 × 当前等级`
- 每消除 10 行升一级，下落间隔缩短
- 最高分写入 `localStorage`（键名 `tetris-high-score`）

## 测试

逻辑在 `game.js`，不依赖 DOM。在本目录运行：

```bash
node --test game.test.mjs
```

覆盖碰撞、旋转与墙踢、消行计分、7-bag、暂停、游戏结束与重新开始。
