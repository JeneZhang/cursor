# 今日小决定

一个很小的网页：写下 2～6 个选项，点大按钮随机选一个。适合刚开始学 HTML / CSS / JS 时阅读。

## 怎么打开

任选一种方式即可。

**方式一：直接打开文件**

用浏览器打开本文件夹里的 `index.html`（双击，或把文件拖进浏览器窗口）。

**方式二：本地小服务器（可选）**

在本文件夹执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 包含哪些文件

- `index.html` — 页面结构
- `style.css` — 样式
- `app.js` — 读取选项、随机抽取、简单动画、用 localStorage 记住上次填写的内容

不需要安装 Node、也不需要打包。
